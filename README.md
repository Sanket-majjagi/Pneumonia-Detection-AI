# Pneumonia Detection using MobileNetV2

## Overview
This project detects Pneumonia from Chest X-Ray images using a fine-tuned MobileNetV2 deep learning model.

## Features
- Transfer Learning using MobileNetV2
- Class imbalance handling with class weights
- GUI for image prediction
- Grad-CAM visualization
- Performance evaluation (Accuracy, Confusion Matrix, ROC Curve)
